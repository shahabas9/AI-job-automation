# AI Job Hunter Frontend

Modern React + Tailwind CSS frontend for the AI Job Hunter platform.

## Features
- **Resume Upload**: Drag & Drop interface to upload resumes and extract profiles.
- **Job Matching**: View matched jobs with AI scoring and explanations.
- **AI Application Prep**: Generate tailored resumes and cover letters for each job.
- **Assisted Apply**: Guided workflow to apply to jobs safely.

## Setup

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## Configuration
- API URL is configured in `src/services/api.js`. Default is `http://localhost:8000`.

## Tech Stack
- React 19
- Tailwind CSS
- Framer Motion (Animations)
- Lucide React (Icons)
- Axios (API Client)
